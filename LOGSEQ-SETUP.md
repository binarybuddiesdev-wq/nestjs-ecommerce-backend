# Logseq Memory Setup — How to Start Before Every Session

## Step 1 — Open Logseq
- Open the Logseq desktop app
- Make sure the `ai-memory` graph is selected (top left)

## Step 2 — Start the API Server
- Click the plug icon (🔌) in the top right
- Click "Start server"
- You should see "Server started" — if not, click it again

## Step 3 — Verify Server is Running
- The 🔌 icon should show the server is active
- If it shows stopped, click it and start again

## Step 4 — Start your AI tool (Antigravity / OpenCode)
- Open Antigravity IDE or OpenCode terminal
- The AI will automatically read from Logseq at the start of the session

## Important Notes
- Logseq MUST be open and server running BEFORE you start your AI tool session
- If you forget to start Logseq first, the AI will warn you and ask you to open it
- Never close Logseq while working — keep it minimized in the taskbar
- Token: saved in `C:\Users\bhargavateja.narasan\.gemini\settings.json`

## If Something Goes Wrong
- AI says it can't connect → check 🔌 icon in Logseq, restart the server
- Server not starting → restart Logseq completely and try again
